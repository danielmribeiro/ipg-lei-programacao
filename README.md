# Programação (Programming)
Repository for the "Programação" course at Instituto Politécnico da Guarda (IPG), part of the "Licenciatura em Engenharia Informática" degree program. This repository contains exercises, resources, and materials related to the study of Programming.


## Course Objectives
Upon completion of this course, students should be able to:
- Design and develop Java applications with a graphical user interface.
- Identify and apply the fundamental concepts of the object-oriented paradigm.
- Model classes and abstract data types in Java.

## Program Contents
- Introduction to Java programming using graphical interfaces.
- Object-Oriented Programming (OOP).
- Object-Oriented Programming in Java.
- Data structures.
- Exception handling.
- Input and Output in Java.
- Graphical User Interface (GUI) in Java.
- Java Database Connectivity (JDBC).

## Learning Methodologies
- Lectures
- Interactive Lessons
- Problem Solving

## Assessment Criteria
- **Continuous Assessment**:
    - Portfolio of exercises completed in class – 20%.
    - Practical exam – 40%.
    - Written exam – 40%.
- **Final Exam (Normal, Resit, or Special Exam Periods)**:
    - Written exam: 60%.
    - Practical component: 40%.
